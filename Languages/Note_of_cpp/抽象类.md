# 抽象类（Abstract Class）

纯虚函数（Pure Virtual Function）是没给出实现的虚函数，函数体用 `=0` 表示。C++中，如果一个类当中包含至少一个纯虚函数，那么这个类就被称为抽象类。

```cpp
virtual void func() = 0;
```

### 抽象类的核心规则：

- 不可实例化：不可以创建一个抽象类的对象。比如现在有抽象类`Shape`，写`Shape s;`的话会直接导致编译报错。

- 强制重写：如果一个类继承自抽象类，必须重写**所有**纯虚函数的具体实现，否则此子类也会变为抽象类。

- 可以有指针与引用：虽然不能创建对象，但你可以声明抽象类的指针或引用，用来指向它的非抽象子类（实现动态绑定）。

### 为何需要抽象类？

抽象类的作用是为派生类提供一个基本框架和一个公共的对外接口，并且强制开发者不要去创建那些没有实际意义的通用对象。

---

实例：动物园管理系统

```cpp
#include <iostream>

// 抽象基类：Animal
class Animal {
public:
    // 纯虚函数：每个动物都会叫，但叫声不同，父类无法给出统一实现
    virtual void makeSound() = 0;

    // 普通成员函数：所有动物都需要呼吸，这个可以统一实现
    void breathe() {
        std::cout << "正在呼吸空气..." << std::endl;
    }

    virtual ~Animal() {} // 别忘了虚析构函数！
};

class Dog : public Animal {
public:
    // 必须实现父类的纯虚函数
    void makeSound() override { // 语法：override
        std::cout << "Woof!" << std::endl;
    }
};

class Cat : public Animal {
public:
    void makeSound() override {
        std::cout << "Meow~" << std::endl;
    }
};

int main() {
    // Animal a; // 报错！抽象类不能实例化

    Animal* myPet1 = new Dog();
    Animal* myPet2 = new Cat();

    myPet1->makeSound(); // 动态绑定到 Dog
    myPet2->makeSound(); // 动态绑定到 Cat

    myPet1->breathe();   // 调用基类的普通成员函数

    delete myPet1;
    delete myPet2;
    return 0;
}
```
