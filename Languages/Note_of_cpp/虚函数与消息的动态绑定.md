# 虚函数与消息的动态绑定

## 虚函数

虚函数是在基类（父类）中使用关键字 `virtual` 声明的**成员函数**。它的作用是告诉编译器：**“这个函数在子类中可能会有不同的实现，请在运行时再决定调用哪一个。”**

其格式如下：

```cpp
virtual <成员函数声明>;
```

一旦基类声明了虚函数，派生类（子类）中对应的函数（函数名、参数、返回值均相同）会自动成为虚函数，无论是否加上 `virtual` 关键字（当然，加上 `override` 是更好的习惯）。

## 绑定（Binding）

分为两种：

- **静态绑定（Static Binding）**： 在程序**编译阶段**就确定了调用哪个函数。这通常基于指针或引用的“字面类型”。

- **动态绑定（Dynamic Binding）**： 在程序**运行阶段**，根据指针或引用所指向的实际对象类型来确定调用哪个函数。

实现动态绑定的前提：1）必须通过**基类**的**指针或引用**来调用函数。 2）调用的函数必须是**虚函数**。

---

### 虚函数表（Vtable）

每一个拥有虚函数的类，编译器都会为其创建一个隐藏的数组，称之为虚函数表。其中，表里面存储的是该类所有虚函数的**地址**。

如果子类重写了父类的虚函数，表里的地址就会更新为子类实现的地址，否则保留的就是父类原有的地址。

### 虚表指针（vptr）

每个拥有虚函数的类产生的**对象**，内部都会多出一个隐藏的指针，指向该类对应的虚函数表。

执行的流程：

1. 程序运行到调用的语句，如`ptr -> draw();`
   
3. 查找`ptr`指向的对象内存
   
5. 找到该对象头部的虚表指针
   
7. 通过虚表指针找到对应的虚函数表
   
9. 在虚函数表中找到`draw()`函数的地址并执行

---

例子如下

```cpp
#include <iostream>

class Shape {
public:
    // 声明虚函数
    virtual void draw() {
        std::cout << "绘制一个通用的形状" << std::endl;
    }
    virtual ~Shape() {} // 虚析构函数很重要！
};

class Circle : public Shape {
public:
    void draw() override { // 重写虚函数 // 语法：override
        std::cout << "绘制一个圆形" << std::endl;
    }
};

class Square : public Shape {
public:
    void draw() override {
        std::cout << "绘制一个正方形" << std::endl;
    }
};

int main() {
    Shape* s1 = new Circle();
    Shape* s2 = new Square();

    // 动态绑定发生在这里
    s1->draw(); // 输出：绘制一个圆形
    s2->draw(); // 输出：绘制一个正方形

    delete s1;
    delete s2;
    return 0;
}
```

在上面的例子中，`s1` 的类型是 `Shape*`（静态类型），但它实际指向的是 `Circle` 对象（动态类型）。因为 `draw` 是虚函数，程序在运行时通过 `s1` 的 `vptr` 找到了 `Circle` 的虚函数表，从而精准调用了圆形的绘制方法。

## 重载（Overload）、重写（Override）和重定义（Hiding/Redefine）

### 重载

重载是指在同一个作用域（比如同一个类）中，存在多个**函数名相同但参数列表不同**的函数。为**静态绑定**。

```cpp
class Calculator {
public:
    int add(int a, int b) { return a + b; }
    double add(double a, double b) { return a + b; } // 重载：参数类型不同
    int add(int a, int b, int c) { return a + b + c; } // 重载：参数个数不同
};
```

### 重写

重写就是上文虚函数与动态绑定的体现。子类重新定义父类中声明为`virtual`的函数。函数名、参数列表、返回值必须与基类**完全一致**。为**动态绑定**。在子类函数后加上 `override` 关键字，让编译器帮你检查是否真的实现了重写。

```cpp
class Animal {
public:
    virtual void speak() { std::cout << "动物在叫"; }
};

class Dog : public Animal {
public:
    void speak() override { std::cout << "汪汪！"; } // 重写：改写父类虚函数的行为
};
```

### 重定义

重定义，也叫**隐藏**，是指子类定义了与父类同名的函数，但是不符合重写的条件。此时，父类的同名函数在子类作用域当中就被屏蔽了。为**静态绑定**。

```cpp
class Parent {
public:
    void fun(int a) { std::cout << "Parent int"; }
};

class Child : public Parent {
public:
    void fun(std::string s) { std::cout << "Child string"; } // 隐藏：参数不同，父类fun(int)被隐藏
};

// 调用示例
Child c;
c.fun("hello"); // 正常
// c.fun(10);   // 报错！Parent::fun(int) 已经被隐藏了，除非使用 c.Parent::fun(10)
```

有如下表格

|   特性   |   重载 (Overload)   |   重写 (Override)   |   重定义 (Hiding)   |
|----------|---------------------|---------------------|--------------------|
|   范围   |   同一个类   |   基类与子类   |   基类与子类   |
|   函数名   |   相同   |   相同   |   相同   |
|   参数列表   |   必须不同   |   必须相同   |   随意（相同或不同）   |
|   virtual语法   |   无要求   |   基类必须有   |   基类必须无 (若参数相同)   |
|   绑定方式   |   静态绑定   |   动态绑定   |   静态绑定   |
|   主要目的   |   同名功能的多样化   |   实现多态性   |   只是简单地替换/屏蔽   |
