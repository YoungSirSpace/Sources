# 操作符重载（Operator Overloading）

允许赋予已有的操作符，比如`+`, `-`, `*` 等，新的含义，使得其能够直接作用于我们自定义的对象。

语法规则如下

```cpp
<返回值类型> operator <操作符符号> (参数列表) {
    // 实现逻辑
}
```

## 两种重载方式

### A.成员函数重载

操作符函数定义在类的内部。对于双目操作符（如 `+`），左操作数必须是该类的对象，因为它会作为 `this` 指针隐式传递。

```cpp
class Complex {
public:
    double real, imag;
    // 重载 + 操作符
    Complex operator+(const Complex& other) { //注意const和&引用
        return {this -> real + other.real, this -> imag + other.imag};
    }
};
// 调用时：c1 + c2 相当于 c1.operator+(c2)
```

### B.全局函数（非成员函数）重载

通常需要配合 `friend` 关键字。当左操作数不是该类对象（例如 `cout << obj`）或者需要对称性（如 `2.0 + complexObj`）时使用。

```cpp
class Complex {
    // ...
    friend Complex operator+(const Complex& a, const Complex& b);
};

Complex operator+(const Complex& a, const Complex& b) {
    return {a.real + b.real, a.imag + b.imag};
}
// 调用时：c1 + c2 相当于 operator+(c1, c2)
```

**常见的重载示例：输出流**`<<`

假设现在要打印一个矩阵。

`<<`必须定义为全局函数，其左操作数是`std:ostream`。比如，`std::cout << Hello`的本质是一个函数调用：`operator << (std::cout, Hello)`

如果我们把重载写在 `Matrix` 类内部，那么调用方式就变成了 `myMatrix << std::cout`; —— 这看起来非常滑稽且不符合逻辑。为了能让 `cout` 在左边，我们必须写一个**全局函数**，让它接收两个参数：左边的流和右边的矩阵。

以下为示例。

```cpp
#include <iostream>
#include <vector>

class Matrix {
private:
    int rows, cols;
    std::vector<std::vector<int>> data;

public:
    Matrix(int r, int c) : rows(r), cols(c), data(r, std::vector<int>(c, 0)) {}

    // 设置数据（简单示例）
    void set(int r, int c, int val) { data[r][c] = val; }

    // 声明为友元，以便全局函数访问私有成员 data
    friend std::ostream& operator<<(std::ostream& os, const Matrix& m);
};

// 全局重载实现
std::ostream& operator<<(std::ostream& os, const Matrix& m) {
    os << "Matrix [" << m.rows << "x" << m.cols << "]:\n";
    for (int i = 0; i < m.rows; ++i) {
        os << "  ";
        for (int j = 0; j < m.cols; ++j) {
            os << m.data[i][j] << " ";
        }
        os << "\n";
    }
    return os; // 返回 os 引用，支持 cout << m1 << m2;
}
```

## 操作符重载的约束

1. 只能重载已有的操作符，比如`+`，不能自创比如`**`。

2. 不能够改变优先级，比如`*`永远比`+`优先计算。

3. 不能改变结合性，比如`=`永远是从右往左结合。

4. 不能改变操作数个数，比如`+`一定要有两个操作数。

5. 内置类型不能动，比如不能重载两个 `int` 相加的含义

6. 五个不能重载的操作符：

   - `.`  成员访问
   - `.*`  成员指针访问
   - `::`  作用域解析
   - `?:`  三目运算符
   - `sizeof`/`typeid`

## 特殊的操作符：前置与后置

为了区分`++i`和`i++`，C++引入了一个占位参数：

```cpp
class Counter {
    int count;
public:
    // 前置 ++i：返回引用，效率更高
    Counter& operator++() {
        count++;
        return *this;
    }
    // 后置 i++：参数里多一个 int 占位符（由编译器自动传 0）
    Counter operator++(int) {
        Counter temp = *this; // 先拷贝一份旧的
        count++;
        return temp;          // 返回旧的副本
    }
};
```
