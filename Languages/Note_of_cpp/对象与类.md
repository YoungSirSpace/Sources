# 对象与类 

对象是用类来创建的，因此，程序中首先要定义类。

C++的类是一种用户自定义类型，语法结构如下：

```cpp
class <类名> { <成员描述> }；
```

成员包括：数据成员和成员函数。类成员标识符的作用域为整个类定义范围。

数据成员是对类的对象所包含的数据描述，它们可以是常量和变量，类型可以是任意的C++类型（void除外）。数据成员有几种访问权限，`private`，`protected`，`public`三种。

如下是一个类的定义。

```cpp
class Cat {
public:
    int weight_value; // 数据成员

    int weight() { // 成员函数
    return weight_value;
    }

    void meow() {
    cout << "Meow" << endl;
    }
};
```

---

在类中声明一个数据成员的类型时，如果未见到相应类型的定义或相应的类型未定义结束，则该数据成员的类型只能是这些类型的指针或引用类型。

### 案例

假设有两个类：User（用户）和 Post（帖子）。用户发了帖子，帖子属于用户。

```cpp
class Post; // 前置声明

class User {
    Post latestPost; // 错误！Post还没有被定义结束，编译器不知道 Post 有多大，无法分配空间
};

class Post {
    User author;
};
```

正确的写法：

```cpp
class Post; // 我先告诉你，有个东西叫 Post，具体长什么样子并不关心

class User {
    Post* latestPost; // 正确！无论 Post 多大，指针的大小是固定的
};

class Post {
    User& author;    // 正确！引用本质上也是通过地址找到对方
};
```

以及其他的需要注意的可能错误的写法：

错误一：在前置声明后尝试调用所声明的类的函数

```cpp
class Engine; // 前置声明

class Car {
    Engine* pEngine;
    
    void start() {
        pEngine->ignite(); // 错误！虽然指针没问题，但编译器不知道 Engine 里有没有 ignite() 方法
    }
};
```

错误二：数组的大小依赖未定义的类型

```cpp
class Brick;

class Wall {
    Brick bricks[10]; // 错误！数组需要知道每一块砖的确切大小才能计算总长度
};
```
