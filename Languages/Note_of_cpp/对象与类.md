# 对象与类 

对象是用类来创建的，因此，程序中首先要定义类。

C++的类是一种用户自定义类型，语法结构如下：

```cpp
class <类名> { <成员描述> }；
```

成员包括：数据成员和成员函数。类成员标识符的作用域为整个类定义范围。

数据成员是对类的对象所包含的数据描述，它们可以是常量和变量，类型可以是任意的C++类型（void除外）。数据成员有几种访问权限，`private`，`protected`，`public`三种。

如下是一个类的定义。

```cpp
class Cat {
public:
    int weight_value; // 数据成员

    int weight() { // 成员函数
    return weight_value;
    }

    void meow() {
    cout << "Meow" << endl;
    }
};
```
