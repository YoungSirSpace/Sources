# 多继承

多继承是指派生类可以有一个以上的直接基类。多继承的派生类定义格式为：

```cpp
class <派生类名>: <继承方式> <基类名1>,
       <继承方式> <基类名2>, …
{ <成员说明表>
};
```

继承方式及访问控制的规定同单继承，派生类拥有所有基类的所有成员。

基类的**声明次序**决定：

- 对基类数据成员的存储安排

- 对基类构造函数/析构函数的调用次序

例如继承`Camera`，`Computer`，`Phone`三个类的`SmartPhone`类。

```cpp
class SmartPhone : public Camera, public Computer, public Phone {
    // 子类自己的新功能
};
```

---

## 多继承中可能问题

- **成员名冲突问题**（二义性）

比如上述程序中，`Computer`和`Phone`都有`start()`成员函数，无法分辨具体调用什么函数。

解决方法： 必须显式指定作用域。例如`myPhone.Camera::start()`。

- **菱形继承（Diamond Problem）**

依旧以上述程序为例。假设`Camera`和`Phone`都继承自`ElectronicDevices`类，含有`SerialNumber`这个属性，因此`Camera`和`Phone`都会有一份自己的单独的`SerialNumber`。在继承的时候，`SmartPhone`便会一同继承，出现两份`SerialNumber`。这不仅浪费空间，还会导致数据不一致。

解决方法：**虚基类**

语法如下：

```cpp
class ElectronicDevices {
public:
    int SerialNumber;
};

class Camera : virtual public ElectronicDevices { // 语法：在中间项中写virtual
    ......
};

class Phone : virtual public ElectronicDevices {
    ......
};

class SmartPhone : public Camera, public Computer, public Phone {
    ......
};
```
虚基类表（Virtual Base Table, vbtable） 的实现机制：

在parent A 的成员变量区，不再直接放置grandparent的成员 $x$，而在原本放 $x$ 的位置，放一个指针（或在虚表里记一个偏移值）。这个指针指向一个表格（vbtable），表格里记录了：“从当前位置开始往后数多少个字节，才能找到真正的 $x$”。
