# 继承 (Inheritance)

继承就是让一个类（子类）能够直接拥有另一个类（父类）的特征和功能，而不需要重新写一遍代码。

基类（base class，或者称为父类，parent class），是被继承的类；派生类（derived class，或者称为子类，child class）。单继承指的是一个类只有一个直接**基类**，多继承是指一个类可以有多个直接**基类**。

## 单继承 (Single Inheritance)

语法格式如下：

```cpp
class <派生类名> : <访问修饰符> <基类名> {
    <派生类的成员说明表>
};
```

例如，以动物为例说明：

```cpp
#include <iostream>
#include <string>

// 基类：动物
class Animal {
public:
    std::string name;
    void eat() {
        std::cout << name << " 正在吃东西..." << std::endl;
    }
};

// 派生类：狗（继承自 Animal）
// 这里的 public 表示“公有继承”
class Dog : public Animal {
public:
    void bark() {
        std::cout << name << " 汪汪叫！" << std::endl;
    }
};

int main() {
    Dog myDog;
    myDog.name = "旺财";
    
    // 旺财可以使用基类的 eat() 方法
    myDog.eat(); 
    
    // 旺财也可以使用自己独有的 bark() 方法
    myDog.bark();

    return 0;
}
```

---

### 访问权限控制

定义中和成员还输的权限，`public`，`protected` 或 `private`，决定了基类的成员在派生类中变成什么样。有如下的表格：

| 基类成员访问权限 | public 继承 | protected 继承 | private 继承 |
|------------------|-------------|----------------|--------------|
| public           | 保持 public | 变为 protected | 变为 private |
| protected        | 保持 protected | 保持 protected | 变为 private |
| private          | 不可见（无法访问） | 不可见 | 不可见 |
